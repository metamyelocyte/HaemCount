# HaemCount

A web reimplementation of the HEMCOUNT differential cell counter.  
Count white blood cells, calculate percentages, and generate formatted reports — all in your browser.

## Features

- Differential counting for peripheral blood and bone marrow
- Real-time histogram (bar or pie chart)
- Customizable keyboard shortcuts
- Backlog to save, load, and manage samples
- Custom sounds for normal and century beeps
- Multiple themes (light, dark, solarized, sepia, pink)
- Adjustable layout — show/hide and reorder panels
- One-click clipboard output
- Offline-ready PWA (works after first online visit)
- No build step — pure HTML, CSS, and JavaScript

## Offline / PWA

Requires a self-hosted `js/chart.umd.min.js` and a root `sw.js` service worker.  
After the first online visit, the app works offline.
