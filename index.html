About HEMCOUNT

HEMCOUNT v1.0 Web

A web-based differential cell counter for hematology, inspired by the original HEMCOUNT desktop application.

This tool helps calculate differential percentages, M:E ratios, and generate clipboard-ready reports for peripheral blood and bone marrow samples.
